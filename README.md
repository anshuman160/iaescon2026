## 🏥 About The Project

This is the official responsive website for the **27th Annual Conference of the Indian Association of Endocrine Surgeons (IAESCON 2026)**, hosted by NSCBMCH, Jabalpur.

The project is a high-performance, single-page application designed to provide delegates with event information, faculty details, fee structures, and a seamless registration process.

** Live Demo:** [https://iaescon2026.onrender.com/]

---

##  Key Features

* ** Professional Medical UI/UX:** Designed with a sterile "Medical Blue & Gold" color palette to reflect trust and authority.
* ** Fully Responsive:** Optimized for all devices (Mobile, Tablet, Desktop) with mobile-specific hero slider adjustments for HD clarity.
* ** Smart Image Loading:** Custom JavaScript implementation to handle complex file extensions (e.g., `.jpg.jpg`) automatically, preventing broken images.
* ** Venue Integration:** Creative hero section with direct Google Maps integration for the venue (NSCBMCH, Jabalpur).
* ** Registration & Payment Flow:** Integrated Registration Fee tables and a direct call-to-action for Google Forms and QR Code payment.
* ** Places of Attraction:** A dedicated gallery section showcasing local tourism spots like Bhedaghat and Bandhavgarh.

---

##  Tech Stack

* **Frontend:** HTML5, CSS3, JavaScript (ES6)
* **Framework:** Bootstrap 5.3 (Grid system & Components)
* **Icons:** FontAwesome 6.4
* **Fonts:** Google Fonts (Lato & Montserrat)
* **Deployment:** Render
